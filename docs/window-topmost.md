# 窗口置顶

左侧竖栏底部、设置齿轮上方增加图钉按钮，首次默认关闭。点击开启置顶，按钮按公共侧栏主题高亮，悬停提示“取消置顶”；再次点击取消。此开关独立于资源/设置面板，切换面板不改变置顶状态。

状态立即保存在用户 `~/.qz-tool/layout.json` 的 `always_on_top` 布尔字段，启动时恢复。布局、日志设置、移除插件和关闭窗口保存均保留此字段。无此字段的旧布局默认关闭；无效类型也按关闭处理。

Windows 通过 `SetWindowPos(HWND_TOPMOST / HWND_NOTOPMOST)` 设置本进程中台窗口，保留位置、大小、窗口句柄及焦点，不使用定时器、反复激活或自定义标题栏。最小化、恢复及最大化仍正常；Windows 同步处理所属弹窗的层级。其他平台及离屏测试使用 Qt 标记作为后备。系统设置失败时恢复按钮原状态并记录错误，不保存假成功。

`pin.svg` 复用活动栏图标着色及公共 QSS，无新增局部样式。资源目录按现有分发流程整体复制，分发检查已增加该图标，未执行打包。

- `tests/test_window_topmost.py` 5项通过：按钮独立、即时保存及重启恢复、其他布局写入保留、无效偏好默认关闭、系统失败回退、Qt后备的可见性及几何/最大化状态。

- 公共主题7项、连接控件10项回归通过。测试使用临时偏好文件、随机端口或自建窗口，未操作用户当前中台或DCC场景。

重启开发中台即可显示图钉按钮，Maya/Max无需重启。

# Max 发送 FBX 到 Maya

第一版在中台 **Max → 选中物体发送到Maya** 中提供无标题QGroupBox包裹的一行三个按钮：打开、导入、设置图标，外层边距与蒙皮卡片一致。仅开发目录更新，未打包。

- **打开到 Maya**：按照用户要求，直接放弃当前 Maya 场景的未保存修改，不询问、不自动保存。随后新建场景并载入 FBX，场景保持未命名，避免以后保存时覆盖交换文件。
- **导入到 Maya**：加入当前场景，每次使用独立命名空间，不合并或覆盖同名角色。
- **设置图标**：浮层提供“导出动画”和“导入后优化显示”两个复选框，均默认开启；点击外部或按 Esc 关闭时自动保存，没有保存、取消或恢复默认按钮。以卡片的屏幕中心定位，并限制在当前画布可见区域和可用屏幕内；窗口属于中台真实窗口，不嵌入画布代理。

其他参数固定使用工具默认值：烘焙和全部重采样开启、Max 当前动画范围、采样步长 1、平滑组和切线开启、三角化关闭。旧版保存的高级选项会被忽略，只保留“导出动画”选择。

使用前重启开发版中台，在 Max 和 Maya 分别重载动作库，并连接两边的桥接。在 Max 选中模型或骨骼后发送，结果只进入中台日志。

发送前会检查 Maya 中实际加载的接收动作版本。若 Maya 仍缓存旧动作，在导出前自动重载并再次核对；重载后仍不匹配则停止发送并报告加载目录，不执行场景替换。当前接收协议版本为3，打开策略为直接放弃未保存修改。预检另检查scene_settings_policy=fbx_native，缺少时在导出前重载并再次核对。Max 导出预检要求 exporter_version=2、settings_policy=animation_only；旧导出动作同样在发送前重载，实际导出和导入不自动重试。

## 导入后优化显示

打开和导入两种发送方式均适用。开启时在FBX载入完成后：关闭自动关键帧，将骨骼整体显示比例设为0.3，仅将本次新增骨骼半径设为1，并检查drawStyle，非0时修正为0；开启骨骼透视、默认材质显示、着色线框及多重采样抗锯齿，最后清空选择。保留原有骨骼的半径，不隐藏挂点、不修改时间范围或当前帧。整体显示比例、自动关键帧及抗锯齿属于全局/场景状态。

打开和导入两种方式均在FBX成功载入、显示处理完成后执行cmds.viewFit(allObjects=True)，使用Maya当前活动视口的相机框选全部；不依赖“导入后优化显示”开关。视口操作失败仅记录警告，不将已完成的导入判为失败。

视口优先使用当前获得焦点的模型视口，否则使用modelPanel4，再回退到其他可用模型视口。没有视口或个别骨骼属性锁定时记录警告并继续处理，不将已成功的FBX导入判为失败。关闭该选项时保持原来的导入后选择根节点行为。

导入选项使用独立的QSettings import_settings保存并单独传给Maya，不混入Max导出参数；原export_settings中的动画开关继续兼容。预检增加display_settings_version=1，缺失时先重载接收动作。

## 来源和坐标

Max导出逻辑保持原样。Maya接收端保留工作单位与上轴，通过FBX原生选项完成转换及时间设置：

- 导出范围为原选择，加上其中每个模型的 Skin 列表中的全部影响节点（包括零权重节点），按节点身份去重；本轮不补父级、不遍历子层级或其他模型。导出成功或失败后恢复原选择及修改面板状态。仍使用原生 `selectedOnly=True` 导出最终选择。复杂角色实测表明，仅依赖原生自动带出骨骼并不可靠。
- 加载 FBX 导出器，`ResetExport` 后逐项设置并读取校验关键参数。设置保留在 Max，不执行 PushSettings/PopSettings。
- 固定开启 Skin，关闭 Shape、点缓存、摄像机、灯光和嵌入贴图；导出动画可关闭。材质兼容、Morph 和控制器重建不在本版范围。
- FBX仍由Max导出为Z-up。Maya不再修改上轴或旋转视图，导入器按当前Maya上轴转换导入数据；不添加工具自建补偿组，不居中或重置变换。XYZ数值不要求跨单位、跨上轴逐项一致。
- 保留Maya当前长度单位，启用FBX自动单位转换（DynamicScaleConversion），不调用currentUnit修改单位。Max 导出动作只在本地把系统单位名称映射到 ConvertUnit；不再额外传递系统单位比例、预估Maya单位或手工坐标比例。
- 有动画时启用FBXImportSetMayaFrameRate、FBXImportFillTimeline及文件TimeLineSpan选项，同时在cmds.file传入importFrameRate=True、importTimeRange=override，由FBX导入器设置场景帧率和范围；静态发送对应使用False和keep。文件命令的时间导入开关独立于FBX插件选项，参见[Autodesk file命令文档](https://help.autodesk.com/cloudhelp/2026/ENU/Maya-Tech-Docs/CommandsPython/file.html)。需要重采样时使用File来源。接收代码不再用currentUnit/time、playbackOptions或currentTime手工设置，不再同步Max当前滑块。静态发送关闭帧率及范围匹配。播放范围可能按首尾关键帧，文件时间跨度用于整体动画范围，不再二次强制覆盖。
- Maya 在重置 FBX 导入参数后明确设置动画 Take：勾选“导出动画”时为 -1（最后一个片段），关闭时为 0（无动画），再调用带 `options='fbx'` 的文件导入。脚本导入不会像文件对话框一样自动选择 Take，详见 [Autodesk 已知问题](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ReleaseNotes/files/2022_release_notes/Maya_ReleaseNotes_2022_release_notes_known_limitations2022_html.html)。预检返回 `animation_take_policy='explicit'`；缺少此能力时在导出前重载动作库并再次检查，保留兼容的接收协议版本 2。
- 原生 FBX/浮点转换不保证小数逐位一致。本版不实现自动重定向、绑定修复或按同名骨架替换动画。

## 文件与失败处理

交换文件位于 `paths.local_data_dir('max_to_maya')`，每次使用独立子目录，界面不提供路径输入。

Maya 接收成功后删除本次 FBX；失败或取消时保留目录并写入中台日志。文件不存在或为空时不会继续接收。不自动重试：超时后 DCC 中的操作可能仍会完成。Maya 接收失败时应检查是否已有部分导入内容。

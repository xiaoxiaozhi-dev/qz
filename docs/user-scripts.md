# Maya / 3ds Max / Blender 用户自定义脚本

## 添加和运行

1. 在资源树打开对应宿主的「用户自定义」组，点击「添加脚本…」。
2. 在文件选择器中选一个或多个文件。Maya 支持 `.py` 和 `.mel`；3ds Max 支持 `.py` 和 `.ms`；Blender 支持 `.py`。
3. 中台把文件复制到 `user_plugins/maya/`、`user_plugins/max/` 或 `user_plugins/blender/` 的第一层，按不带扩展名的文件名显示并自动刷新。遇到同名工具会跳过并记录日志，原始文件保持不变。
4. 连接对应宿主，双击脚本条目即可运行；也可在画布的 Ctrl+F 搜索中选中。用户脚本不生成卡片，同一个脚本在执行期间不会被重复提交。

也可以手动把文件放进对应目录，再点资源树顶部的「刷新」。顶部搜索框同时筛选官方插件和用户脚本。添加、刷新、搜索过滤和恢复布局均不会执行脚本。

新加入的独立脚本无需 `manifest.json`，执行整个文件。如果 Python 脚本只定义了函数，需要脚本自行调用入口，例如用 `if __name__ == '__main__':`。文件选择器只复制选中的文件，不自动收集依赖。脚本需要的其他环境和依赖仍由对应宿主提供。

## 管理

- 右键「改名」会重命名独立脚本文件；「打开脚本目录」打开其宿主目录；「移除」确认后只删除选中的文件。
- 旧版带 `manifest.json` 和 `files/` 的工具继续可用，包括原有依赖和设置过的入口。右键可以修改旧工具入口，移除时确认删除该工具的整个目录。旧布局中保存的脚本卡片会跳过。
- 用户脚本随 `user_plugins/` 保存。搬迁到另一台电脑时可复制这个目录；官方更新包不会覆盖它。

## 固定到宿主

连接 Maya 或 3ds Max 后，可右键脚本，分别选择「固定到 Maya 当前工具架」或「固定到 Max 工具栏」。固定只添加启动按钮，不执行脚本；按钮建好后可在宿主直接运行脚本，不必开启中台。

独立脚本的固定按钮按文件名对应，改名后需要重新固定，并手动删除旧按钮。旧清单工具仍按原 ID 识别。移动中台目录后也需要重新固定，以更新宿主按钮记录的路径。

## 执行与日志

脚本在对应软件主线程执行，中台在后台等待结果。Python 输出和错误写入中台日志，MEL / MAXScript 的部分原生输出仍留在宿主。执行超时或通信失败后不会自动重试；关闭中台也不会取消宿主已开始的脚本。

# Max 顶点颜色

插件位于中台「3ds Max → 顶点颜色」，宿主为 3ds Max 2020 / Python 2.7；卡片仍使用中台 Python 3 / PySide6。

## 当前功能

- Color（0）、Alpha（-2）、Illumination（-1）、M17（17）、M18（18）五个编辑通道，顶部名称使用 Color。
- Color、Illumination、M17、M18 使用 R/G/B 数值及分量勾选，各 0–255，滑块与数字框双向同步；未勾选分量保持原始浮点值，不量化或改写。
- Alpha 使用独立 A 滑块/数值（0–255），不受 RGB 数值和分量开关影响。
- 设置、缩放、渐变和普通粘贴按0–255整数写入：设置颜色/预设直接写整数，渐变、缩放及粘贴在计算后四舍五入（0.5进位）并限制到0–255，再除以255交给Max存储。只量化本次写入分量；未勾选分量、选区外颜色与其他通道不变。Max仍使用float32，换算可能有微小表示误差，不代表额外小数颜色。
- 原脚本的 20 个颜色预设改为纯色按钮，不显示数值文字；悬停提示显示 R/G/B 值。该提示是用户明确要求的例外；另「应用缩放」按钮按用户要求显示倍率说明提示，其余业务按钮仍不加 tooltip。
- 预设分组保留边框、不显示标题；预设点击后直接向当前 Color、Illumination、M17 或 M18 通道应用颜色，遵守分量勾选，**不改变上方 RGB/A 滑块或数字框**。Alpha 通道禁用颜色预设。
- 用户实际切换顶部单选框时，发送一次独立显示动作，自动开启 Max 当前对象对应通道的显示；M17/M18 使用 `#map_channel` 和 `vertexColorMapChannel=17/18`。保留数值与勾选，仅切换显示不写入或初始化映射数据。
- 打开卡片和点击已选中的单选框不自动调用；没有合适选中对象或连接失败时写入日志。显示切换允许对象层级/空子对象选区，不要求进入基础对象编辑；实际改色仍需要有效子对象选区。
- 「Editable Poly 当前子对象选区」右侧新增「显示数值」勾选，默认关闭。开启后在当前活动视口的选中顶点旁显示红/绿/蓝三个0–255整数，没有RGB/A字母前缀；五个通道格式相同，Alpha读取实际x/y/z，不单独变成白色A或将x复制三遍。使用Max原生文字及黑色细阴影，不创建Qt覆盖窗口。
- 数值显示跟随顶部当前通道和RGB分量勾选。Alpha下开启显示时允许操作RGB勾选，仅用于控制数字显示，RGB滑块/数字框仍禁用，原有Alpha设色、缩放、渐变及选择规则不变。每个几何顶点取当前通道最小map顶点ID的颜色；外部小数颜色只在显示时四舍五入，不修改实际数据。
- 只读基础Editable Poly当前子对象选区，顶点/边/边界/面/元素都可展开；每帧按几何ID顺序最多检查前500个选中顶点，超出时日志提示。无单个有效对象、对象层级、空选区、未建立通道或无面映射时显示为空，不创建颜色。选区、映射、颜色和位置在Max重绘时重新读取，无共享几何映射缓存；视图旋转、缩放时重新投影，屏幕外和相机后方不绘制。文字不做顶点间避让或模型遮挡检测。
- 底部说明只保留「改色不支持 Ctrl+Z。」一行。渐变自定义/拓扑面板显隐以及状态文字变更后，按当前宽度重新计算本卡片内容高度，保留卡片宽度和画布位置；收起后自动缩回，不将展开时的剩余高度分摊到底部。
- 关闭开关/卡片或正常退出中台时注销显示；重载动作库、打开/新建/重置场景时也清理。中台每2秒只续约/检查显示会话状态，断连后停止续约，Max在30秒超时后的下次重绘清理。只读绘制不标记场景修改，不保存到MAX文件。
- 业务结果与失败原因进入中台日志，成功结果注明通道，Alpha 明确记录 A 值。
- 新增「按颜色选择顶点（当前选区）」及独立容差滑块/数值框，范围0–255、默认0。复用顶部通道、RGB目标及勾选，Alpha用A目标且忽略RGB勾选。目标200、容差10匹配[190,210]含端点及中间小数，超出范围截到0–255；容差0为精确匹配，不把199.6取整为200。只改变选区并切到顶点层级，不修改颜色、映射或显示。
- 按颜色选择在当前几何选区内筛选，RGB所有勾选分量必须在同一个颜色顶点上同时满足；同一几何顶点有多个颜色角点时任意一角匹配即可。没有匹配时清空顶点选区；通道未建立/为空、选区为空或数据无效时保持原选区并提示。数值、预设、容差、缩放和渐变控制互不改写。
- 同一卡片增加「复制顶点色」「粘贴（最近点）」「粘贴（镜像 X）」及源对象/通道/顶点数状态。复制当前通道与当前几何选区，每个源几何顶点固定取最小颜色顶点编号的原始三分量浮点值；粘贴到顶部当前选中的任意通道，按世界坐标寻找全局最近源点，等距时取最小源几何顶点编号。镜像以世界X=0为平面，复用剪贴板。RGB类目标遵守分量勾选；Alpha目标接收三个独立分量，不转换成灰度，标准Alpha仍由x决定。两种粘贴都在写入前分别取整/限制范围，不按源通道作分量转换。日志显示源通道→目标通道。
- 颜色剪贴板为Max当前动作会话中的独立快照，不使用系统剪贴板。复制时建立可复用KD树，不修改场景；随后源移动、改色或删除不改变快照。再次成功复制替换快照，失败保留上次数据；重载动作库/重启Max后失效，需要重新复制。目标其他分量、其他通道和选区外顶点保持原值，必要时分离共享颜色映射；目标缺失通道按现有规则初始化白色。
- 「粘贴（顶点 ID）」在目标选区中按几何顶点编号查找同 ID 的已复制颜色。模型的摆放和变形不会影响匹配。没有源 ID 或无法写入颜色的目标顶点会跳过，日志汇总粘贴与跳过数量。适用于顶点编号对应的模型，顶点数相同不能证明编号对应。
- 拓扑复制和粘贴使用独立剪贴板，支持顶部当前选中的 Color、Alpha、Illumination、M17、M18；粘贴时通道必须和复制时一致。先在源 Editable Poly 的子对象层级选择区域，点击「复制（拓扑）」；再在目标模型选中要修改的区域，点击「粘贴（拓扑）」。边或面选区会展开为它们包含的几何顶点。只写入两个选区在拓扑对应后的交集，保留通道的原始浮点精度。Alpha 不受 RGB 分量开关影响，其他通道遵守 RGB 分量开关；日志汇总跳过的顶点。
- 该模式检查整模面连接，不要求顶点 ID、位置、尺寸或 UV 完全一致。UV 辅助匹配；重复网格片使用确定点附近的几何位置区分。无法安全确定对应、存在源选区颜色接缝或计算期间更换目标和选区时，不写入。普通复制及其他粘贴模式继续使用原剪贴板。
- 同一卡片新增「颜色缩放」：倍率滑块与数字框双向同步，范围 0.00–10.00、精度 0.01，默认 1.00；仅点击「应用缩放（当前选区）」时执行。RGB/A 设置值与预设、倍率互不改写。
- 缩放分组保留边框、不显示标题；倍率说明使用按钮tooltip「每次点击按当前颜色乘倍率，结果四舍五入为 0–255 整数。」（用户明确要求的提示例外）。
- 缩放读取当前颜色乘倍率，再按0–255四舍五入并限制范围。Color、Illumination、M17、M18只缩放勾选的RGB分量，Alpha使用原标量x乘倍率并写为灰度三元组，忽略RGB勾选；未勾选分量原样保留。
- 倍率1.00也执行本次写入分量的取整，可将外部小数颜色转为整数；空通道仍从白色/不透明开始。每次点击均按上次实际写入后的颜色计算，再取整，不将多次倍率合并后只取整一次。选区外保持原色或初始化白色。
- 渐变使用八个互斥单选框：世界方向 X/Y/Z、-X/-Y/-Z、「自定义（两点）」和其右侧的「沿拓扑」，默认 -Z（从上到下）。六个正负轴方向同一行，自定义与沿拓扑位于下一行；方向选择与顶部目标通道各自独立。分组保留边框、无标题。
- 渐变最小值、最大值各为 0–255（默认 0、255），沿方向从最小值过渡到最大值；两个数值独立，支持按源脚本输入下降范围。曲线滑块/数字框为 25–75，50 为线性，25 前慢后快、75 前快后慢，使用源脚本相同二次函数。
- 渐变复用顶部目标通道和上方 RGB 勾选，允许任意分量组合，未勾选分量保留原始浮点值。Alpha 直接使用同一最小/最大值做透明度渐变，忽略 RGB 勾选。上方 RGB/A 数字仅用于设置颜色，不参与渐变计算；预设、倍率、范围和曲线彼此不改写。
- 世界轴模式按选区内参与着色顶点在该有向世界轴上的投影最小、最大位置确定范围；单点或该轴无跨度时日志提示并保持数据和显示不变。无面角点的孤立顶点不参与轴向范围。位置从基础 Editable Poly 读取并乘 objectTransform，包含物体位移、旋转、缩放与枢轴偏移。
- 自定义模式显示「设置起点（选区中心）」「设置终点（选区中心）」和坐标状态。每次只读捕获当前展开为几何顶点的选区世界坐标平均中心，不改色、不改显示、不创建通道。点位为捕获时的世界坐标快照，切换方向/通道保留点位；缺失、重合或无效点位不会写入。
- 自定义两点同时定义方向和长度。顶点沿起点到终点方向投影并映射到 0–1，区间外保持端值，再应用曲线和数值范围；应用时的当前选区只决定哪些顶点改色，不重新归一化两点范围。
- 沿拓扑模式显示「记录起始横线」「记录结束横线」及对象/边数状态。可选择完整横线/边环，也可选单边自动补全并高亮；三角面方向不明确时参考另一端已记录横线消歧。支持闭环转开放横排及反向。起始排对应最小值，结束排对应最大值，按排数均分后应用曲线；不依赖UV、空间轴或边长，不改变模型拓扑。
- 沿拓扑支持保留连续横排结构的三角面、四边面及混合面发片，包括已验证的部分横排点数变化。首尾切分唯一面区域，再从两端计算连接步数并校验横排、侧边界和面层级；缺面、漏选、分叉、非流形或无法确认一致横排时仅记录原因，不写入。
- 同样适用于衣服等规则条带片区。两条横线必须在同一个元素（连通片）内，只检查这个元素的面类型、退化面和非流形边，不要求整个衣服对象都满足限制。其他元素的多边面和异常连接不影响本片；所选元素内存在不支持的多边面时提示其边数，即使该面位于首尾横线之外也会检查。检查通过后，仍仅在两横线之间应用渐变。
- 横线记录保存在当前 Max 动作会话内，最多保留最近 64 次记录；对象删除、替换基础对象、拓扑改变、重载动作库或重启后必须重新记录。普通变形、移动、颜色及映射变化不影响记录；不向对象增加标记、不保存 UV 或几何到颜色映射缓存。卡片重建后也需重新记录。
- 拓扑模式应用范围来自已记录的两横线，忽略应用时的当前子对象选区，允许取消边选择或退回对象层级，但仍需选择同一基础对象。所有参与顶点的相邻颜色角点都更新，包含首尾横线两侧以保持连续；区间外其他几何顶点保留原值。

## 使用

1. 重启开发目录中的中台，连接 Max 2020，在 Max 插件「重载动作库」点击重载。
2. 在 Max 只选择一个 Editable Poly 对象，在修改面板激活基础 Editable Poly。
3. 在顶点、边、边界、面或元素层级选择要操作的部分。
4. 选择 Color / Alpha / Illumination / M17 / M18，Max 同步切换对应通道显示。Color、Illumination、M17、M18 下调整 RGB 和分量勾选，点击对应设置按钮；或直接点击纯色预设。Alpha 下调整 A 并点击「设置 Alpha（当前选区）」。
5. 调整「颜色缩放」倍率并点击「应用缩放（当前选区）」：例如 0.50 将当前颜色减半，2.00 加倍并限制上限。缩放与上方 RGB/A 数值无关；Alpha 下缩放当前透明度。
6. 渐变选择世界方向（默认 -Z），调整最小值、最大值及曲线，上方勾选所需 RGB 分量，点击「应用渐变（当前选区）」；Alpha 下直接处理透明度。
7. 自定义渐变：选择「自定义（两点）」，在 Max 选择第一组顶点并记录起点，再选择另一组记录终点；最后选中实际要改色的部分并应用。起点对应最小值，终点对应最大值，两点外保持端值。捕获两个点本身不写颜色。
8. 拓扑渐变：选择「沿拓扑」，在 Max 边层级选中完整起始横线并记录，再选完整结束横线并记录。保持同一基础对象，调整范围/曲线及分量，点击「应用渐变（两横线之间）」。不需要额外选中中间横排；曲线 50 时按排数平均分配。起终点可位于发片中段，交换两条横线可交换方向。
9. 按颜色选点：在Max子对象层级选定搜索区域，选择目标通道，设置RGB/A目标值及容差，点击「按颜色选择顶点（当前选区）」。结果替换顶点选区并切换到顶点层级；再次搜索前按需要重新选定搜索区域。
10. 复制粘贴：在源对象子对象层级选定范围，选择源通道并点击「复制顶点色」；再选择目标对象、子对象范围及任意目标通道，点击「粘贴（最近点）」。RGB类目标可勾选所需分量，Alpha目标直接写入全部三分量。无需相同顶点数量或编号，也可同对象跨通道粘贴。位置和三分量始终取复制时的原始快照，不因源/目标通道类型转换。

设置颜色、缩放、世界轴及自定义两点渐变按几何顶点范围处理：边/面/元素选择先展开成顶点，修改这些几何顶点对应的全部颜色角点。沿拓扑渐变同样更新识别到的几何顶点的全部相邻颜色角点。
普通改色在对象层级、空选区不写入；沿拓扑模式记录成功后可在对象层级应用。所有模式均不处理多对象、不支持对象或修改器子对象，不自动转换/塌陷模型。

## 颜色数据处理

每次调用重新读取映射，不缓存上一次拓扑。保留现有颜色接缝；颜色顶点若同时供选中和未选中的几何顶点使用，只分离选中部分的颜色映射。
共享的目标颜色顶点只写一次。未建立目标通道时新建逐几何顶点的白色映射，选区外保持白色（Alpha 保持 255/不透明）；不改其他通道、几何拓扑或子对象选择。
渐变在写入前按「原颜色顶点 ID + 最终颜色」规划目标映射：同一颜色顶点被不同位置共用、需要不同渐变色时拆分；选区外继续使用原 ID。原有不同颜色顶点不会合并，未勾选分量精确保留；同一原 ID 且最终颜色相同的角点共享一次写入，重复应用同一渐变不继续增加映射。映射规划每次重新读取，无持久缓存或单独共享映射层。
标准Alpha使用映射顶点x分量；设置A、缩放A和渐变继续按标量同步为灰度三元组。复制/粘贴则按用户要求保留并传递全部原始三分量，不额外转换成灰度，也不把A当作Color通道的第四分量。

**与原脚本一致，当前改色不支持 Ctrl+Z。** Max 2020 实测中，底层 `polyop.setMapVert` / 映射调整不会因包上 `pymxs.undo(True)` 就获得完整撤销。
因此不创建只能撤销显示属性的误导性撤销条目。写入失败时显式恢复原映射、目标旧颜色和显示属性（含原 `vertexColorMapChannel`）；恢复本身也失败时日志明确报告可能部分更新，不声称已恢复。纯显示切换失败也尝试恢复原显示属性，不涉及颜色数据恢复。

## 文件

- `max_actions/vertex_color.py`：`vertex_color` 动作在 `channel=0/-1/17/18` 时使用 `rgb=[r,g,b]`、`mask=[bool,bool,bool]`，`channel=-2` 时使用 `alpha=a`。channel 默认 0，保留首阶段旧调用兼容。`vertex_color_display(channel=...)` 只切换显示。纯 Python 2.7 兼容，不导入 Qt。
- `vertex_color_scale(factor=1.0, mask=None, channel=0)`：倍率必须为有限数值且处于 0–10；非 Alpha 通道须传三个布尔分量开关，Alpha 忽略 mask。不接受布尔倍率、字符串、NaN/Inf。所有目标值在写入前计算并检查，复用现有选区保护与失败恢复；无持久映射缓存。
- `vertex_color_select(rgb=None, mask=None, channel=0, alpha=None, tolerance=0)`：容差为0–255整数，Alpha只比较x；RGB对勾选分量逐一比较。用Max Point3相同float32表示比较区间端点和当前颜色，避免量化到8位整数或使用额外固定误差。读完所有参与映射并验证后才改选区，写入失败恢复原顶点选区及子对象层级。
- `vertex_color_numbers(enabled=False, channel=0, mask=None, owner=None)` / `vertex_color_numbers_status(owner=None)`：设置或查询原生数值显示；enabled严格布尔值，五通道的mask均为三个布尔值，owner是卡片生成的32位小写十六进制会话标识。返回enabled/channel/mask/count/limited/error/limit；状态查询不返回顶点数据，只续约匹配owner的现有显示。过期卡片不能关闭或续约其他卡片的显示。关闭/重载只移除本功能的回调，异常记录原因后停止显示，界面在状态查询时同步取消勾选。
- `vertex_color_copy(channel=0)`：返回源名、通道、复制及跳过顶点数；当前通道的最小颜色顶点编号作为每个源几何顶点的代表色，保留完整浮点值及世界坐标。会话内保存一个快照和索引。
- `vertex_color_paste(channel=0, mask=None, mirror_x=False, by_vertex_id=False)`：允许五通道任意组合，快照中的源通道仅用作状态和日志；写入分量统一四舍五入到0–255整数。mirror_x将目标世界查询位置取(-x,y,z)。by_vertex_id直接查找剪贴板中的几何顶点编号，额外返回skipped，不能与mirror_x同时开启。各模式共用角点规划、共享映射分离与失败恢复，保持选区和层级。最近点与镜像共用`max_actions/_vertex_color_nearest.py`中的Python 2.7兼容KD树，重合源位置及等距时按最小几何ID选取。
- `vertex_color_gradient(direction='-Z', minimum=0, maximum=255, curve=50, mask=None, channel=0, start=None, end=None)`：方向接受 X/Y/Z、-X/-Y/-Z、custom、topology。最小/最大值为 0–255 整数，曲线为 25–75 整数；非 Alpha 须传 RGB 布尔 mask，Alpha 忽略 mask。custom 须传两个世界坐标；topology 须传两个横线记录 token。写入前完成识别、曲线与映射规划，失败恢复原计数、面映射、旧颜色及四项显示属性。
- `vertex_color_gradient_edges()`：只读记录边/边界层级的一条连续开放边链，返回 record（会话内 token）、edges、vertices、object。最终完整横排及条带校验在应用前执行；记录按钮本身不改色、不切换显示。
- `max_actions/_vertex_color_topology.py`：Python 2.7 兼容的纯拓扑识别，只接收面连接与首尾边链，不读取位置、UV 或颜色数据。
- `vertex_color_gradient_point()`：在有效基础 Editable Poly 子对象选区上只读返回 `point=[x,y,z]`、vertices、object；按展开后的几何顶点去重后求世界中心，独立于目标颜色通道和 RGB 勾选。

# 官方插件与用户插件管理

官方 Maya/Max 插件右键仅保留“打开插件位置”。改名、删除入口已取消，主窗口处理器也拒绝这两种操作，以便官方文件随发布清单统一更新。不修改现有插件的名称或目录。

用户自定义脚本继续支持改名、修改入口、打开目录、确认删除以及固定到 Maya 工具架/Max 工具栏，详见 [user-scripts.md](user-scripts.md)。

ui/plugin_management.py 仅负责校验并定位官方插件目录；目录必须是 plugins/<dcc>/ 的直接子目录，登记 ID/DCC 与条目一致。tests/test_plugin_management.py 验证两端实际右键菜单、打开位置、禁止直接发起改名删除及路径校验。用户脚本管理另有原专项。

历史版本曾支持官方插件改名和删除，现由本规则替代。已有手工改过的官方文件不会在本次整理中被恢复，后续官方更新将按发布清单替换。

# JS 动作工具

Maya 分支中的「JS 动作工具」用于管理 JSON 动作文件及对应的覆盖动画层。
中台仅显示 UI、搜索本地文件并通过桥接发请求；场景操作在 Maya 主线程执行。
动作核心位于 `maya_actions/_js_anim_core.py`，不需要恢复已移除的 `maya_core` 目录。
卡片继承项目公共控件样式，后台结果通过公共日志入口在 UI 线程记录。

## 使用

1. 从本次源码启动中台，在 Maya 连接设置中执行启动代码。
   已使用本次源码连接的 Maya 可以用「重载动作库」注册新增 action。
2. 打开 Maya → JS 动作工具。动作目录固定为 `temp/js_anim_pose_json/`，不提供目录选择。
   Git 独立工作区中没有该目录时，会读取主工作区中的同名目录。
3. 在 Maya 中选择骨架根节点，每次导入直接使用当前选择，无需额外读取或填写根节点。
   换场景或换角色后应重新选择根节点；同一批次在第一次成功导入后固定目标骨架。
4. 搜索动作，双击或点击「导入选中」，支持从动作列表多选导入。
5. 「场景图层」中点击动作切换预览，点击「基础动画」关闭 JS 动作图层。
   「刷新」同步磁盘文件及场景图层；删除图层可以在 Maya 中撤销。

常用按钮按「导入选中 / 删除图层」排列，下方「刷新」占满整行。
低频「导出 JSON… / 批量导出 JSON…」放在底部无标题折叠栏内，默认收起，仅显示一根细分隔线。
入口没有按钮外框、背景或箭头；悬停时细线略微提亮。点击线附近可展开/收起按钮，
不执行导出操作；每次重新打开卡片都恢复收起状态。
卡片不显示日志或结果文字，全部结果及错误写入中台日志；处理期间仅显示进度条。

多文件依次处理，中台显示进度，单文件业务错误会写入日志并继续下一项；
连接中断或超时会停止后续任务。
每个请求最多等待 600 秒。超时或关闭卡片不代表 Maya 已取消执行，
应等待 Maya 完成并刷新图层后再重试。

## 旧 JSON 兼容

支持原工具 v5.1/v5.2 生成的文件，无需转换或重写：

```json
{"nodes":{"hip":{"parent":null,"ch":{"tx":[[0,1],[10,5]]}}}}
```

- 保留原始帧号，包括第 0 帧；缺失的六个位置/旋转通道在动作起始帧补 0。
- 节点匹配忽略命名空间，使用根节点范围内的短名称。
- 保留旧规则：只记录、比较 joint 父级；普通 transform 包装组按 null 处理。
- 名称和骨架结构一致时可复用；缺失节点、父级不符会跳过并记录日志。
  重名歧义、锁定通道和无匹配节点会在修改前报错。
- 使用覆盖层及 `noResolve=True` 写入原值；旧文件沿用 Maya 默认切线行为。
- 同名动作沿用旧工具的 `AJT_<文件名MD5前8位>` 命名，保留 displayName/startFrame/endFrame。
  重新导入先写临时层，成功后替换；写入失败会回滚，不删除旧动作。
  新图层记录根节点，同名动作已绑定其他骨架时会提示，避免覆盖其他角色。

旧文件没有帧率、单位、切线或完整动作范围。插件使用当前场景单位，
并按文件现存关键帧推算起止帧，无法恢复导出时已经丢弃的信息。
相同命名和层级之外，还应使用一致的骨架朝向、旋转顺序和单位。

## 导出

普通导出和批量导出均支持可选模板：模板有效且能识别体型时，先将动作转换到标准骨架；没有模板或无法识别体型时，直接按原骨架常规导出JSON。动作导入、图层切换和删除不变。

在折叠区的导出按钮上方选择骨架模板 FBX，可直接输入路径或点击输入框右侧的文件夹图标。模板由用户存放在任意稳定目录，工具记住上次路径；不再依赖`temp/js_anim_pose_fbx/`，也不复制模板到临时目录长期保存。

体型只从所选模板文件名的 F1/F2/M1/M2 前缀识别，例如`F1.fbx`或`M1_标准骨架.fbx`；场景名、源动作名和导出文件名均可自由命名。普通导出和整批导出共用当前选择的模板，使用模板批量转换时请选择同一体型的动作；更换体型前先切换模板。留空、文件缺失、空文件、非FBX或无法识别体型均回退常规导出，不再阻止操作；日志注明实际模式。已识别且载入失败、骨架不匹配等转换错误仍报错，不会静默回退。两个桥接API可传`template_path`；不传则常规导出。脚本还可传`body_type`用于已重命名的模板，若文件名含体型前缀则仍要求一致。

- 「导出 JSON…」：在Maya选择源骨架根节点，使用当前播放范围；未选择时沿用唯一Armature回退规则。输入文件名后转换并保存到固定动作目录。支持小数起止帧，额外采样不落在整数步长上的结束帧。
- 「批量导出 JSON…」：逐个在独立命名空间载入源FBX，使用有效模板时转换，否则直接采样源骨架；均使用源FBX帧率及完整动画范围，包括末尾没有新关键帧的停留。常规模式优先使用源中的Armature根节点，否则要求唯一根节点。无需替换、保存或重开当前场景；同名输出仍在开始前确认。

F1源缺少Forearmnub时，通过肘部位置、手腕方向及上臂Z轴重建左右主前臂；若源中已有该节点则直接使用。F2/M1/M2直接使用源Forearm。M1保留Point01～04的实际变换，自动发现根Bip01；其他模板的Bone_Allnub包装组同样保留。所有同名骨骼用原生父子约束传递世界位置和旋转，保持模板父子结构，再烘焙为模板本地通道。

模板副本先清除旧动画，并保留第0帧的静态缩放、骨骼朝向及包装节点；不导出缩放动画。模板中缺少对应源的必要骨骼会报错，源中超出模板的附属骨骼不进入标准JSON。

转换完成后清理临时节点，恢复场景帧率、范围、当前帧、选择、命名空间、自动关键帧和修改状态；帧率恢复同时保持原曲线时间。源角色的动画曲线不删改。临时节点按UUID识别，保留共享USD管理节点。清理失败会报告，只有清理和恢复成功后才原子写入最终JSON，失败不会覆盖原有动作。

JSON继续采用format_version=2、nodes/parent/ch、六个位移/旋转通道以及单位、范围、线性插值信息。低层采样器仍位于_js_anim_core.py，新的模板转换入口位于_js_anim_export.py；两个桥接导出action已转接新入口。

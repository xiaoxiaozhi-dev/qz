# 侧边栏、分组与画布视口恢复

正常关闭中台时，将资源树折叠组、画布视口正中心对应的场景坐标及缩放比例保存到 `data/layout.json`。启动恢复窗口几何、节点和布局后恢复视口，不按场景矩形或全部插件范围重新居中。

侧边栏的打开/关闭及当前资源页或设置页也会保存：`sidebar` 为 `{ "visible": true, "page": 0 }`，0 表示资源，1 表示设置。启动先恢复侧栏布局和图标选中状态，再恢复画布视口。恢复设置页不触发额外的设置点击或连接查询。专注模式的临时隐藏不覆盖进入前的侧栏状态；专注模式本身不跨启动恢复。旧记录没有此字段时默认关闭侧栏。

折叠组使用稳定键：`["dcc", "maya"]`、`["dcc", "max"]`，子组为 `["cat", "maya", "settings"]` 等。子组状态与父组独立；父组收起时仍保留子组的选择。刷新插件、开关卡片和改变配色时不重新展开用户收起的组。首次运行或新组默认展开。

`canvas_view` 保存 `{ "center": { "x": 0.0, "y": 0.0 }, "scale": 1.0 }`。中心取实际 viewport 的几何中心，保留半像素，避免 QRect.center 整数取整造成连续启动偏移。缩放使用当前画布实际比例；空画布也能保存。恢复在现有延迟布局流程最后完成，并沿用 AnchorViewCenter，以适应最大化、侧栏显示和视口尺寸变化。Qt滚动条为整数，允许一个屏幕像素以内的坐标量化误差。

布局继续兼容 v1–v4；新字段为 v4 的可选扩展。旧记录没有视口时保留原默认行为，不猜测或用节点中心代替。未知/畸形折叠键和非有限/无效视图值回落默认，不妨碍其他布局状态。日志上限、置顶、窗口、卡片删除等保存路径均保留新字段。

`tests/test_layout_restore.py` 9项在临时目录及自建窗口验证实际键盘折叠、关闭再打开、两端/子组独立、卡片坐标保留、真实中键平移和缩放后的视口恢复、空画布及3次重复启动无漂移、最大化、其他设置写入保留、旧记录兼容和异常数据。侧栏覆盖资源/设置页开关、图标高亮、恢复不触发设置点击、专注模式退出应用后的恢复及视口保持。侧栏增量的专注模式、置顶、设置和公共样式回归通过。不接触用户 DCC 场景或实际设置。

本轮仅修改开发代码，未重新打包。重启开发中台加载后，调整折叠与观察位置并正常关闭，后续启动恢复；此前没有记录的视口无法追溯恢复。
